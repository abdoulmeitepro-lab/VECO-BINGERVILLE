# VÉCO · Le club vélo d'Abidjan-Est

Site vitrine et réservation du club vélo VÉCO, à Bingerville (Côte d'Ivoire).

## Contenu

- `index.html` : le site complet (une seule page, avec ses onglets)
- `images/` : les photos et illustrations
- `pay/` : les logos des moyens de paiement
- `feedback.js` : le bouton « Donner mon avis » (commentaires envoyés vers le Google Sheet)

## Mise en ligne

Site statique : aucun serveur ni installation n'est nécessaire.

- **GitHub Pages** : Settings › Pages › Source « Deploy from a branch », branche `main`, dossier `/ (root)`.
- **Netlify** : glisser-déposer ce dossier, ou relier le dépôt GitHub (aucune commande de build).

Le fichier `.nojekyll` évite que GitHub Pages transforme le site.

## Mettre à jour

Remplacer tout le contenu du dépôt par la nouvelle version du dossier, puis faire un commit.
